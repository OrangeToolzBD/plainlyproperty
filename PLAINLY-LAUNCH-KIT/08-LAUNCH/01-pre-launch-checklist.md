# Pre-launch checklist

Ordered. Do not skip ahead — an early failure makes later steps moot.

## Week 0 — before any code

- [ ] **Start Google advertiser identity verification.** Property advertising in the UAE requires
      it, and a newly-licensed broker can lose 2–3 weeks to the process — exactly when the paid
      bridge is needed. This is the single most time-critical item in the kit.
- [ ] Confirm the broker's BRN and the firm's ORN, and the DLD register entry that proves them
- [ ] Register the domain. Not the broker's personal name
- [ ] Agree the inspection-partner referral arrangement (you will rank for snagging before
      anything else — have somewhere to send the work)
- [ ] Agree the single phone number that will always be answered

## Week 1 — the gate

- [ ] Choose SSG or prerendering. **Not a client-only SPA** — see `05-SEO-AEO-GEO/01-technical-gate.md`
- [ ] `curl` test passes for `<h1>`, `<title>` and JSON-LD on a stub route
- [ ] `robots.txt` deployed with the AI search bots explicitly allowed
- [ ] `sitemap.xml` deployed and submitted to Google Search Console and Bing
- [ ] `llms.txt` deployed
- [ ] Analytics + Search Console verified, GA4 AI channel group created

## Weeks 1–2 — page 01 only

- [ ] `/property-valuation-dubai/` built to its page spec
- [ ] Definition of done fully ticked
- [ ] Valuation form tested end to end, including the 24-hour report delivery
- [ ] **15-minute callback rule agreed in writing.** The forecast's one-in-three close rate assumes
      fast follow-up. Without it that ratio is fiction and the model falls over
- [ ] Privacy notice live before the form collects anything

## Week 2 — start advertising

- [ ] Campaign live on valuation terms only, narrow match
- [ ] Budget set from the pessimistic column, not the optimistic one — see the table below
- [ ] Conversion tracking on the form, not on the page view

## Weeks 3–8 — measure, then decide

- [ ] Measure the **real** click-to-enquiry rate and re-budget from it
- [ ] Only then build the snagging cluster (pages 04, 05, 06)
- [ ] Log an AI-citation baseline: 8 questions × 5 runs × 4 engines, before organic traction

## Budget the pessimistic case

| Click → enquiry | Cost per listing won | Return |
|---|---|---|
| 1.0%, one listing per four enquiries | **AED 18,540** | 1.4x – 3.8x |
| 3.0%, one in three | AED 4,681 | 5.6x – 15.0x |

A new site with no reviews and no track record converts at the **low** end. Budget
**AED 18,540 per listing** and be pleased to spend less. It returns more than it
costs at every point on that table.
